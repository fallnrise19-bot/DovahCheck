# Content rules

## Editions

DovahCheck separates content into:

- Base Game
- Dawnguard
- Hearthfire
- Dragonborn
- Free Creations included with current Special Edition
- Anniversary / Creation Club bundled content

A character selects a content profile so unavailable content does not block 100% completion.

## Branches

Known mutually exclusive routes are modeled as route groups, including Civil War alignment, Dawnguard faction choice, Dark Brotherhood alternatives and Thirsk outcomes.

## Artwork

Repository artwork must be original DovahCheck artwork. Canonical game imagery may be used as research/reference for accuracy, but ripped Bethesda assets are not the app asset pipeline.

## Research

The Google Drive master remains the research/audit workspace. Versioned JSON committed to this repository is the app input. Changes should be reviewed in Drive first, then exported into a new data version.
