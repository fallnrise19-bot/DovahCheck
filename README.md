# DovahCheck

DovahCheck is an Android completionist companion for The Elder Scrolls V: Skyrim.

The app is being built around a structured quest and collection database rather than hard-coded screens. It is designed to support multiple character profiles, edition-aware content, spoiler controls, route-aware completion, repeatable quest handling, themed faction/Hold sections, and later collection tracking.

Status: foundation in progress.

## Planned content profiles

- Original Skyrim (2011)
- Legendary Edition
- Special Edition
- Anniversary Edition / Upgrade
- Custom installed-content profile

## Data principles

- Display titles are not database identities.
- Mutually exclusive routes must still allow reachable 100% completion.
- Infinite radiant quests count as a completed template after the player completes one instance.
- Finite repeatables store an explicit required iteration count.
- Raw imported research is kept separate from cleaned app data.
- Original DovahCheck artwork will be used in the repository; game artwork is reference material only.
